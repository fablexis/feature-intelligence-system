Maqueta de la prioridad: cuatro tarjetas-pestaña, barra de pesos y filas que se despliegan con los factores.

**Qué aporta quien lo usa.** Banda, puntuación, factores con su cálculo, el argumento en contra y el esquema de pesos.

**Reglas.** La banda siempre lleva su palabra. La suma se muestra completa. El desacuerdo se registra junto a la banda original.
