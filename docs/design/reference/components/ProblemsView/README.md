Maqueta de la lista de problemas con filtro deslizante y filas que entran en cascada.

**Qué aporta quien lo usa.** Cada problema con cuentas afectadas, solicitudes, avisos y votos.

**Reglas.** El orden es por amplitud, no por prioridad, y la página lo dice. El filtro anima las filas al cambiar; si no hay resultados, lo explica.
