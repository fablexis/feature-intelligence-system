Las piezas que se repiten: banda, aviso ámbar, contador, medida, medidor con umbral, procedencia, botones, campos y control segmentado.

**Reglas.** La banda lleva la palabra. El ámbar tiene un solo significado. Botones de 48 px mínimo (40 en pequeño), texto de 16. El medidor marca el umbral con una línea.
