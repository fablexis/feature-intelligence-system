Maqueta de la cola de revisión: lista a la izquierda y una decisión por vez a la derecha con medidor y umbral.

**Qué aporta quien lo usa.** La solicitud, el problema donde quedó, el veredicto, la confianza, el umbral y el progreso.

**Reglas.** Acciones siempre al pie de la tarjeta. Al decidir, la tarjeta sale animada y aparece un aviso. Rechazar no borra; se puede deshacer.
