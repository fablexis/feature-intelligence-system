Maqueta de nueva solicitud: formulario amplio, selector de canal deslizante y proceso de cinco pasos animado.

**Qué aporta quien lo usa.** Título, descripción, canal y cuenta; recibe uno de tres resultados: ya existe, probablemente existe o es nuevo.

**Reglas.** El proceso muestra qué hace el sistema paso a paso. Cada resultado dice con qué certeza actuó y deja una salida ("Actually, mine is different").
